EDITION AND PERMISSION CHECKS
The current UI gives CE section create/edit controls. An earlier four-role
authenticated API test in PCI Automation Review showed CE section writes succeed
and Admin, Encoder and Viewer writes fail. The original project has the section
policy migration, but this guide did not retest its API permissions or write data.
The current app still says D6433-24 on Sampling Plans, My Inspections /
Inspections to Review (severity guidance and provisional calculation controls),
and Settings (calculation edition and catalog rules). The calculator and sample
planning rules are still provisional D6433-24 work; this script tests the
software workflow only. ASTM D6433-07 engineering rules, curves and results
must be implemented and independently validated before any real approval or
publication demonstration.
